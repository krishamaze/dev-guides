## 🤝 Contributing

Got a guide idea? Found an error? Contributions welcome!

### Suggest a Guide

1. Open an [Issue](https://github.com/krishamaze/dev-guides/issues) with the label `guide-request`
2. Describe what you'd like to see covered
3. Mention potential cost savings or productivity gains

### Fix an Error

1. Fork the repo
2. Make your changes
3. Submit a Pull Request

### Write a Guide

1. Use the [guide template](./templates/guide-template.html)
2. Follow the existing style (practical, no-BS, conversational)
3. Include real-world examples and cost/time savings
4. Submit a PR
