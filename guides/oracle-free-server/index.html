Why Oracle?

Most "Free Tiers" from AWS or GCP expire after 12 months. Oracle's Always Free tier is actually forever. For Indian startups and indie devs, this is a goldmine. You can run multiple production-grade microservices, a heavy database, or even a build server without paying a single paisa.

Real World Math

An equivalent AWS instance (t4g.xlarge) would cost you roughly $180/month. That's approx 15,000 saved every single month.

The Specs

Oracle offers ARM-based "Ampere" shapes that are surprisingly fast:

  • 4 vCPUs (ARM Ampere)
  • 24 GB RAM
  • 200 GB Block Storage
  • 10 TB Egress bandwidth per month

Step 1: Signing up safely

Signing up from India can be tricky. Use a card that has International Transactions enabled. They will do a small temporary charge (around 80-100 INR) to verify your card and refund it immediately.

Warning

Do NOT use a virtual card or some prepaid cards. Oracle's fraud detection is aggressive. Use a proper HDFC/ICICI/SBI Debit or Credit card.

Step 2: Spinning up the Instance

When creating your instance, make sure to select the "Always Free Eligible" image. Specifically, look for Oracle Linux or Ubuntu with the VM.Standard.A1.Flex shape.

config 
Shape: VM.Standard.A1.Flex
OCPU count: 4
Memory (GB): 24

Step 3: Opening Ports

Oracle has two firewalls: one in the Cloud Dashboard (Security Lists) and one on the OS. You need to open both. If you only open it in Ubuntu, your site still won't work.

bash 
# On Ubuntu, to open HTTP/HTTPS
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save

Avoiding "Out of Capacity"

Sometimes you'll see "Out of host capacity" in popular regions like Mumbai or Hyderabad.

The Fix: Use a simple terraform script or a python script to keep retrying the API every minute. Usually, you'll get one within 24-48 hours when someone else deletes their instance.
